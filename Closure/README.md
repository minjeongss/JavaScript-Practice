# 클로저(Closure)에 대해 분석해보자! ⚡

## 클로저 정의

클로저란 다음의 조건을 `모두` 충족하는 중첩 함수를 뜻한다.

- 중첩 함수가 외부(상위) 함수보다 더 오래 유지된다.
- 중첩 함수가 외부(상위) 함수의 변수를 참조한다.

> 예시: BasicClosure.js

## 렉시컬 환경 VS 렉시컬 스코프

### 렉시컬 환경

별자와 스코프를 관리하는 컴포넌트이다.
객체 형태의 스코프를 생성하여, 식별자를 키로 등록하고 값을 바인딩한다.

구성 요소는 다음과 같다.

- 환경 레코드: 식별자 관리
- 외부 렉시컬 환경에 대한 참조: 스코프 관리

### 렉시컬 스코프

렉시컬 스코프란 상위 스코프에 대한 참조 환경이며, 상위 스코프는 함수의 정의 위치를 기준으로 결정된다.

이때 상위 스코프에 대한 참조는 렉시컬 환경의 `외부 렉시컬 환경`에 대한 참조에 저장할 참조값이다.

함수 객체는 내부 슬록 [[Environment]]에 저장한 렉시컬 환경의 참조인 상위 스코프를 기억한다.

### 렉시컬 환경 VS 렉시컬 스코프

렉시컬 환경의 `외부 렉시컬 환경에 대한 참조`를 담당하는 것이 렉시컬 스코프이다.

## 클로저 활용

### 정보 은닉

상태(변수)가 외부의 요소에 의해 변경되지 않고, 특정 함수에게만 상태 변경을 허용하여 상태를 안전하게 변경 및 유지를 할 수 있다.

> 예시: HiddenValueClosure.js
