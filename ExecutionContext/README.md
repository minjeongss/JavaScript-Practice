## 실행 컨텍스트란

식별자(변수, 함수, 클래스)를 등록하고 관리하는 스코프와 코드 실행 순서를 관리하는 영역이다. 이때, 식별자와 스코프는 렉시컬 환경으로 관리한다.

실행 컨텍스트는 스택 자료구조로 관리되며, `실행 컨텍스트 스택`이라 불린다.

실행 컨텍스트의 구성 요소는 다음과 같다.

- LexicalEnvironment 컴포넌트
  - 환경 레코드: 식별자 관리
  - 외부 렉시컬 환경에 대한 참조: 스코프 관리
- VariableEnvironment 컴포넌트
- this 바인딩

### LexicalEnvironment VS VariableEnvironment

- VariableEnvironment
  - 정체: 선언 시점의 LexicalEnvironment의 스냅샷
  - 변경 사항이 반영되지 않는다.
- LexicalEnvironment
  - 정체: 최초의 VariableEnvironment의 복사본
  - 변경 사항이 실시간으로 반영된다.

### 렉시컬 환경

식별자와 스코프를 관리하는 컴포넌트이다.
객체 형태의 스코프를 생성하여, 식별자를 키로 등록하고 값을 바인딩한다.

## 실행 컨텍스트 종류

- 전역 실행 컨텍스트
- 함수 실행 컨텍스트
- eval 실행 컨텍스트
- 모듈 실행 컨텍스트

## 실행 컨텍스트 생성 과정

1. 소스코드 평가

   - 실행 컨텍스트 생성
   - 렉시컬 환경 등록(선언문 실행) > 환경 레코드 생성

   - this 바인딩
   - 외부 렉시컬 환경에 대한 참조 결정
     - 상위 스코프를 가리키며, 단방향 링크드 리스트인 스코프 체인을 구현한다.

2. 소스코드 실행
   - 식별자 검색 및 결정
   - 값 할당
3. 소스코드 실행 결과는 실행 컨텍스트가 관리하는 스코프에 등록
4. 소스코드 실행 종료
5. 실행 컨텍스트 삭제

#### 전역 환경 레코드 생성

- 객체 환경 레코드 생성
  - 관리하는 값
    - var 키워드 선언한 전역 변수, 전역 함수
    - 빌트인 전역 프로퍼티, 빌트인 전역 함수, 표준 빌트인 객체
  - 연결된 객체: BindingObject

var 키워드로 선언한 전역 변수와 전역 함수의 경우, BindingObject를 통해 전역 객체의 프로퍼티와 메서드가 된다. 그렇기에 window로 참조가 가능하다.

- 선언적 환경 레코드 생성

  - 관리하는 값
    - let, const 키워드 선언한 전역 변수

let, const 키워드로 선언한 전역 변수는 전역 객체의 프로퍼티가 되지 않기에, window로 참조가 불가능하다.

#### this 바인딩

전역 환경 레코드의 [[GlobalThisValue]]
내부 슬롯에 this가 바인딩되며, 전역 코드의 this는 전역 객체를 가리킨다.

전역 환경 레코드와 함수 환경 레코드에서만 this 바인딩이 이루어진다. 객체 환경 레코드와 선언적 환경 레코드에선 this 바인딩이 이루어지지 않는다.

#### 외부 렉시컬 환경에 대한 참조 결정

전역 코드의 상위 스코프는 없기에 null이 할당된다.

### 3. 전역 코드 실행

- 식별자 검색 및 결정

실행 중인 실행 컨텍스트에서 식별자 검색 후, 참조할 스코프를 찾는다.
현재 스코프에서 식별자가 존재하지 않는다면, 상위 스코프로 이동해 검색을 반복한다.

- 전역 변수 x,y 값 할당

> process.js의 구조를 바탕으로 진행된다.

### 1. 전역 함수(globalFunction 함수) 코드 평가

1. 함수 실행 컨텍스트 생성
2. 함수 렉시컬 환경 생성

#### 함수 환경 레코드 생성

등록 및 관리하는 대상은 다음과 같다.

- 매개변수
- arguments 객체
- 함수 내부에서 선언한 지역 변수
- 함수 내부에서 선언한 중첩 함수

#### this 바인딩

함수 환경 레코드의 [[ThisValue]] 내부 슬롯에 this가 바인딩된다.
이때, 일반 함수로 호출되어 this는 전역 객체가 된다.

#### 외부 렉시컬 환경에 대한 참조 결정

전역 실행 컨텍스트가 할당된다.

함수 객체를 생성할 때, 함수의 상위 스코프를 함수 객체의 내부 슬롯 [[Environment]]에 저장한다.

### 2. 전역 함수 코드 실행

- 식별자 검색 및 결정
- 지역 변수 x,y 할당

## 함수 레벨 스코프 VS 블록 레벨 스코프

- 함수 레벨 스코프

  - 대상: var 키워드로 선언한 변수

함수 코드 블록만 지역 스코프로 인정한다.

- 블록 레벨 스코프
  - 대상: let, const 키워드로 선언한 변수

모든 코드 블록(함수, 조건문, try/catch문)을 지역 스코프로 인정한다.
